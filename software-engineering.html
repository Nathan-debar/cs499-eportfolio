Artifact Overview

This artifact is based on the CS-340 Grazioso Salvare Animal Shelter CRUD application. The original program was designed to interact with a MongoDB database and provide basic create, read, update, and delete functionality for managing animal shelter records.

The enhancement focused on improving the overall software design by restructuring the application into a more modular and maintainable format. This included separating responsibilities, improving readability, and implementing structured validation and error handling. These improvements ensure the application can scale more effectively and be more easily maintained or extended in future development.

Enhancement Highlights

  • Refactored code for modularity and separation of concerns
  • Implemented input validation for safer data handling
  • Added structured error handling for reliability
  • Improved readability and maintainability of the codebase
