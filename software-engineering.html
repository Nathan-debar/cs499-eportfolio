Artifact Overview

This artifact is based on the CS-340 Grazioso Salvare Animal Shelter CRUD application. The original program was designed to interact with a MongoDB database and provide create, read, update, and delete functionality for managing animal shelter records.

The enhancement focused on improving the overall software design by restructuring the application into a more modular and maintainable format. This included separating responsibilities, improving readability, and implementing structured validation and error handling. These improvements better align the artifact with software engineering practices related to maintainability, clarity, and system reliability.

Enhancement Highlights

The enhancement introduced cleaner separation of responsibilities, more reusable support methods, stronger input validation, and improved exception handling. Together, these changes transformed the application from a basic functional implementation into a more organized and maintainable software solution.
